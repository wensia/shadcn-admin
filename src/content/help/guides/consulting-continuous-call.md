# 咨询：连续外呼

连续外呼适合顾问集中处理一批待拨打线索，系统会按队列推进，减少在列表和详情页之间反复切换。

## 使用场景

- 今日需要集中拨打新分配线索。
- 需要按筛选条件处理某一批线索。
- 需要快速完成未接通、待二次联系等队列。

## 操作步骤

1. 打开 [连续外呼](/crm/continuous-call)。
2. 选择或确认当前外呼队列。
3. 查看当前线索基本信息和历史记录。
4. 发起外呼。
5. 通话结束后记录结果，并设置下一步动作。
6. 点击下一条，继续处理队列中的线索。

## 外呼后必须记录

| 结果 | 建议动作 |
| --- | --- |
| 接通且有意向 | 更新意向等级，设置下一次回访 |
| 接通但暂不考虑 | 写明拒绝原因，按规则调整状态 |
| 未接通 | 记录未接通，并设置合理的再次拨打时间 |
| 空号或错误号码 | 标记异常，避免后续继续拨打 |

## 与通话记录的关系

通话明细可在 [通话记录](/crm/call-records) 查看。若通话记录与线索跟进不一致，以线索详情中的跟进记录作为业务交接依据。

## 提效建议

- 外呼前先确认筛选条件，避免队列混入非本人负责线索。
- 每次通话结束立即记录，不要等队列完成后再补。
- 对高意向线索优先设置明确的下一步时间。
