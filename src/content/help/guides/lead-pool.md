# 咨询：公海领取

公海用于存放当前无明确负责人、可重新分配或可领取的线索。顾问可按团队规则从公海领取后继续跟进。

## 领取前先确认

1. 打开 [公海线索](/crm/leads/pool)。
2. 使用年级、来源、校区、最近跟进时间等条件筛选。
3. 查看线索历史跟进，确认是否适合继续跟进。
4. 按团队规则领取线索。

## 领取后要做什么

- 立即查看完整资料和历史备注。
- 判断是否需要当天回访。
- 补充新的跟进记录和下一次回访时间。
- 对无效线索按规则更新状态，不要长期占用。

## 常见规则

| 场景 | 建议处理 |
| --- | --- |
| 线索最近刚被释放 | 先查看释放原因 |
| 多个顾问同时关注 | 以系统领取结果为准 |
| 领取后发现号码无效 | 标记异常并记录说明 |
| 家长重新表现出意向 | 更新意向等级并进入正常跟进 |

## 注意事项

公海领取不是简单抢线索。领取后需要承担后续跟进责任，避免领取后无记录、无回访、无状态更新。
