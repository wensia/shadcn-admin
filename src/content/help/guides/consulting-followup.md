# 咨询：快捷回访与线索标注

咨询顾问在工作台完成日常回访，并通过跟进记录、意向等级和标签让线索状态保持清晰。

## 推荐入口

优先使用 [咨询工作台](/crm/workbench) 处理今日跟进。需要批量筛选或查看完整资料时，再进入 [线索管理](/crm/leads)。

## 快捷回访流程

1. 在工作台打开待回访线索。
2. 查看历史跟进记录、意向等级和备注。
3. 发起电话或记录本次沟通结果。
4. 更新跟进结果、下次回访时间和意向等级。
5. 根据沟通内容补充标签，例如试听意向、预算情况、年级需求。
6. 保存后继续处理下一条线索。

## 标注建议

| 标注项 | 何时更新 | 用途 |
| --- | --- | --- |
| 意向等级 | 每次关键沟通后 | 帮助主管判断转化优先级 |
| 跟进结果 | 每次回访后 | 记录本次联系是否有效 |
| 下次回访时间 | 需要继续跟进时 | 进入后续提醒和日控安排 |
| 标签 | 用户画像变化时 | 支持筛选和精细化运营 |

## 记录标准

跟进记录要能让其他同事接手。建议包含：

```text
本次沟通结果 + 家长关注点 + 下一步动作 + 预计回访时间
```

## 注意事项

- 没接通也要记录结果，避免重复无效拨打。
- 家长明确拒绝时，应按团队规则更新状态，不要长期挂在待跟进。
- 重要承诺要写入备注，避免后续履约遗漏。
