# 市场：批量导入线索

市场同事可通过批量导入把外部表格中的线索录入 CRM，减少逐条创建的时间。

## 适用场景

- 地推、活动、投放等渠道产生了一批新线索。
- 线索已经整理为统一表格，需要一次性录入。
- 需要在导入后检查失败原因或重复数据。

## 操作步骤

1. 打开 [批量导入](/crm/batch-import)。
2. 下载或参考当前系统要求的导入模板。
3. 按模板填写线索姓名、手机号、年级、来源渠道等字段。
4. 上传文件并确认字段映射。
5. 提交导入任务，等待系统返回成功和失败数量。
6. 到 [创建日志](/crm/lead-creation-logs) 查看导入结果。

## 字段检查

| 字段 | 要求 | 说明 |
| --- | --- | --- |
| 手机号 | 必填 | 用于识别重复线索和后续外呼 |
| 姓名 | 建议填写 | 不确定时可填写家长称呼或学生称呼 |
| 年级 | 建议填写 | 方便咨询按年级筛选 |
| 来源渠道 | 必填或按团队要求填写 | 用于后续统计投放效果 |
| 校区 | 按实际情况填写 | 影响后续归属和跟进安排 |

## 常见问题

### 导入后部分数据失败怎么办

先下载失败明细，按错误提示修正字段格式，再重新导入失败数据。不要把已经成功导入的数据再次混入文件，避免重复创建。

### 系统提示手机号重复怎么办

重复线索通常已经存在于 CRM。请在 [线索管理](/crm/leads) 中搜索手机号，确认当前负责人和跟进状态，再按团队规则处理。

### 如何确认渠道是否填对

导入前先与主管确认渠道命名规则。渠道名称写法不统一会影响市场数据统计。
