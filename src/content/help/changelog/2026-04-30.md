# 更新历史：2026-04-30

## 帮助中心第一版上线

本次上线 CRM 内置帮助中心，员工可从侧边栏进入，浏览使用教程和更新历史。

## 新增内容

| 类型 | 内容 |
| --- | --- |
| 使用教程 | 市场批量导入、批量分配、创建分配任务 |
| 使用教程 | 咨询快捷回访、线索标注、连续外呼、公海领取 |
| 使用教程 | 教管学员、课包、排课、消课基础流程 |
| 更新历史 | 从本版本开始记录员工需要关注的系统变化 |
| 内部流程 | 部署流程开始迁移到项目 Skill，详见 [部署流程 Skill 化](/help-center?doc=changelog-deploy-skill-2026-04-30) |

## 功能能力

- 支持按文档类型切换：全部、使用教程、更新历史。
- 支持搜索标题、摘要、正文和适用部门。
- 支持文档目录和当前文档标题目录。
- 支持通过 URL 参数 `doc` 直接打开指定文档。
- Markdown 中的 CRM 内部链接会在当前系统内跳转。

## 使用说明

从 [帮助中心](/help-center?doc=overview) 开始阅读。后续功能更新、入口调整和重要操作规范会继续补充到这里。
